# Feedback

We welcome feedback, bug reports, and suggestions for Alpine Zoom.

## How to Reach Us

- **Telegram:** [@MartiAi_Feedback_bot](https://t.me/MartiAi_Feedback_bot) — send messages directly
- **GitHub Issues:** [alpine-zoom-sar/issues](https://github.com/andreisminsk/alpine-zoom-sar/issues) — open a new issue

## What to Include

When reporting a bug or issue, please include:

- The command you ran (e.g., `az-video source_video/clip.mp4`)
- The full error message or unexpected behavior
- Your environment: OS, Python version, Ollama version
- The `report.json` file (if one was generated) — it contains analysis parameters and results

## Feature Requests

Feature requests and ideas for improvement are welcome. Open a GitHub issue with the label `enhancement` or send a message via Telegram.
